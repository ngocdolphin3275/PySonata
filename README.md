## About

PySonata brings the everyday parts of managing and enjoying a music collection into one compact desktop application. Move between your player, library, playlists, lyrics and audio tools without having to piece together several separate utilities.

The application is designed around a practical idea: advanced capabilities should remain understandable, and the main listening workflow should stay easy to use.

## Features

- **Music player and library** — play local audio, browse a searchable collection, and move between songs, albums, artists and folders.
- **Playlists and queue** — organize listening sessions and work with local and supported online playlist entries.
- **Online music** — search and play supported public sources, open supported URLs and download available audio.
- **Lyrics** — find lyrics automatically or manually, display synchronized lines, and save lyrics into supported audio metadata.
- **Metadata and cover art** — inspect and edit audio tags and manage embedded artwork.
- **Audio tools** — use the equalizer, inspect sound with the spectrogram, and convert audio through the integrated FFmpeg workflow.
- **Themes and languages** — choose the visual theme and use the interface in Vietnamese, English, Japanese or Simplified Chinese.

## Download and run

The current project release is **PySonata 3.9.95**, a portable Windows x64 build.

1. Open [GitHub Releases](https://github.com/ngocdolphin3275/PySonata/releases) and download `PySonata-Windows-x64.zip`.
2. Extract the ZIP to a folder on your PC.
3. Open the extracted `PySonata` folder and run `PySonata.exe`.
4. Keep the extracted folder structure intact. The application relies on the bundled Qt, media, helper and license files beside the executable.

No separate Python installation or application installer is required.

### Release assets

| File | Purpose |
|---|---|
| `PySonata-Windows-x64.zip` | The portable application and the runtime files required to run it. |
| `PySonata-ThirdParty-Sources-and-Licenses.zip` | Third-party corresponding-source archives, license and copyright material, notices, build information and relinking instructions. This is a companion compliance archive, not PySonata application source code. |

The runtime package already contains the third-party notices and license texts needed with the distributed binaries. The companion archive provides the associated source and additional license materials.
